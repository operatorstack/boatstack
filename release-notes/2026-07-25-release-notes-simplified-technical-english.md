### Release notes now use Simplified Technical English

Contributors write each Boatstack release note by hand. The README already follows
Simplified Technical English. The release notes did not state the same rule.

The contributor guide now requires it. Each new release-note fragment uses Simplified
Technical English: short sentences, the active voice, the present tense, one idea per
sentence, condition-first phrasing, and simple words. This keeps the notes easy to skim
and easy to translate, for both people and models.

The rule applies to new fragments only. Published fragments stay unchanged, because the
release-note contract is append-only.
